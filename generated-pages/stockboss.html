StockBoss · Gutenberg image generation

Stock images without prompt chaos.

StockBoss adds an image-generation block to Gutenberg that uses OpenRouter image models, reusable system prompts, reference images, and Media Library import so editors can produce consistent visual assets from inside WordPress.

Workflow

From image idea to reusable asset.

StockBoss keeps the creative loop inside WordPress: generate, preview, import, place, and iterate without jumping between model tools, download folders, and manual uploads.

Inside the block

Prompt writes the subject. Reference image provides visual direction. Override prompt lets advanced editors change the system instruction for one image. Iterate Image appears on image blocks so a selected result can be refined in place.

Prompt → brand system prompt → optional references → OpenRouter model → Media Library image → editable WordPress block

Controls

Team settings for repeatable output.

The settings page centralizes encrypted provider keys, defaults, and visual references so teams do not have to teach every editor model names, prompt formulas, or image-reference habits.

Provider keys

Per-image overrides

Reference images and system-prompt overrides are available when a specific asset needs special direction.
