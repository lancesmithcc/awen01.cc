Why Cycles

Your site can match the moment without anyone rebuilding pages.

Static colour systems are good at consistency. Cyclical colour systems add context. They let a site feel calmer at night, brighter in the morning, more festive on holidays, more urgent during launches, and normal again when the moment passes.

Rule Order

When two schedules overlap, the clearer rule wins.

Each palette rule can include a date range, time range, timezone, recurrence pattern, priority number, and scope. The plugin checks which rules are active and applies the highest-priority match to GeneratePress and GenerateBlocks surfaces.

How it works

1. Check the site's timezone and current time.
2. Find colour rules active for this page, post type, or the whole site.
3. If more than one rule applies, use the highest-priority rule.
4. Output the matching CSS variables.
5. Let GeneratePress and GenerateBlocks inherit the active colours.
