UltraBGs

BrandBoss · Plugin

BrandBoss

Captures your brand — logo, palette, typography, voice, spacing, imagery, rules — and regenerates synchronized human and machine outputs on every save.

brand.json — structured tokens, a full contrast matrix, and resolved asset URLs in one file.

brand.md — an AI execution brief written for agents to build on-brand without guessing.

tokens.css + GP sync — drop-in custom properties; syncs GeneratePress global colors and fonts.

Guide page + PDF — an auto-built guide in your own tokens, plus a print-ready PDF.

Reference images — global and per-block references for a steady visual style.

Media Library — generations import automatically with prompt-based titles.

BrandBoss · Rust WASM

WASM Color Engine

The brand color and contrast math, compiled from Rust to WebAssembly and running natively in the browser — identical output, no server round-trip.

Byte-for-byte port — hex↔sRGB, linear, and OKLCH with gamut clamping.

WCAG contrast — luminance and contrast ratios at native speed.

Runs in the browser — color math in WebAssembly, no PHP call per render.

Identical output — drop-in replacement, zero visual drift from the PHP engine.

BrandBoss · Rust WASM

Typography Engine

The modular type scale and spacing math, compiled to WebAssembly — identical ratios, no server round-trip.

Modular type scale — base 18, ratio 1.25, computed in the browser.

8px spacing scale — the full spacing ramp from the design system.

Layout ratios — the shared proportion math behind the grid.

Identical output — drop-in replacement for the PHP math.

UltraBGs · Rust WASM

Render Math Engine

The shared noise, easing, and color-mixing math that powers every UltraBGs pack, running natively in WebAssembly.

Value noise — the generative field behind the backgrounds.

DLT · Rust WASM

Theme-Mode Engine

The dark / light / transcendent mode resolution, compiled to WebAssembly and resolved in the browser.

Mode resolution — stored, default, and prefers-color-scheme precedence.

Fallback chain — deterministic fallback when no mode is set.

Cycling — mode rotation logic in the browser.

Zero flash — resolved before first paint, no server round-trip.
